# WorkPortal – Virtual Career Fair

WorkPortal is a Virtual Career Fair platform designed to connect students/job seekers with recruiters and provide an organized environment for managing career opportunities.

- Developed the **Recruiter Backend**, including recruiter-related functionality and pages.
- Integrated the front-end with the corresponding backend features.

### Nour
